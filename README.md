# AIRO — Autonomous Incident Remediation Operator

SLO-driven autonomous incident remediation for Kubernetes workloads.

## Project Overview
AIRO is a Kubernetes-native closed-loop reliability controller that converts sustained SLO burn-rate violations into safe, bounded, and verifiable remediation actions.

## Quick Start
```bash

# Clone the project repository
git clone https://github.com/hesam-fattahi/airo.git

# Build the binary
make build

# Run the project locally
make run
```
